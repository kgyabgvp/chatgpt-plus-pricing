## 單月、長期訂閱和續費有什麼差別？

WildAI 的教學文件把訂閱方式分為單次訂閱與長期訂閱。

單次訂閱通常代表購買一個月，到期後不會自動延續。長期訂閱則可能是多個月連續訂閱，價格通常會比單月方案更優惠，但也可能涉及預存金額或按月自動續費。

購買前要特別注意「多月訂閱」的運作方式。WildAI 公開教學提醒，長期方案可能會先預存多個月的金額，再按月自動續費。如果你在 ChatGPT 官方頁面自行取消訂閱，可能導致後續預付月份無法繼續使用。

可以按照下面方式選：

- 只想試用一個月：選單月或單次訂閱。
- 已經確定會持續使用：比較多月方案的總價和每月平均價格。
- 想從 Plus 升級到 Pro：先確認目前週期、剩餘月份和升級後的退款規則。
- 不確定自己是否需要高額度：先從 Plus 開始，不要一開始就買高階方案。
- 需要公司或工作帳號：先確認帳號交由第三方流程處理是否符合組織規定。

官方 Plus 本身沒有年繳選項；第三方平台提供的多月方案，則屬於平台自己的訂閱流程，兩者不能混為一談。

## ChatGPT Plus 不包含哪些東西？

ChatGPT Plus 和 OpenAI API 是兩套獨立的計費系統。購買 Plus 後，不代表你會取得 API 額度，也不能直接用 Plus 訂閱抵扣 API 費用。若你要在程式、網站或自動化工具中呼叫 OpenAI API，仍需要另外設定 API 帳號與付款方式。

另外，Plus 也不是無限量服務。以下情況仍可能受到限制：

- 特定模型有訊息上限。
- 圖像生成可能有使用額度。
- 深度研究等工具可能受到額度或開放狀態影響。
- 高峰時段可能出現暫時性的使用限制。
- 不同帳號、地區或功能推出階段可能看到不同選項。

如果你的需求是 API 串接、批量自動化或大量程式請求，應直接研究 API 定價，而不是把 ChatGPT Plus 當作開發者方案。
